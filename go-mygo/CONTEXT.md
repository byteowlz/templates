# Domain vocabulary

- **Service**: deterministic Go substrate shared by native/headless adapters.
- **Fixture**: explicit immutable synthetic example, never a live-device fallback.
- **Snapshot**: portable document with baseline revision and ordered items.
- **Envelope**: v1 structured result or stable machine-readable failure.
- **Native view**: MyGo GPU ui.View calling Go directly, with no Page/webview.
- **Role**: closed semantic color intent resolved by the canonical adapter.
- **Readiness**: scoped reproduced evidence, not permission or certification.

# Domain vocabulary

- **Service**: deterministic Go substrate shared by headless and desktop adapters.
- **Fixture**: explicitly synthetic immutable sample; never a real device fallback.
- **Snapshot**: portable versioned fixture document with revision and ordered items.
- **Envelope**: v1 machine reply containing exactly one result or stable failure.
- **Desktop facade**: only the semantic operations bound to MyGo IPC.
- **Scheme**: Base16/Base24 slot data interpreted by the shared design-system engine.
- **Readiness**: reproduced scoped evidence; neither authorization nor certification.

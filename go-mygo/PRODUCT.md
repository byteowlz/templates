# Template purpose

Audience: byteowlz developers scaffolding a lightweight desktop tool.
Task: run one deterministic Go service through typed desktop IPC and a
semantic JSON CLI, retaining portable design/config contracts.

Explicit brief: stable MyGo system-webview mode, Bun/TypeScript, embedded
assets, shared Base24/R1 engine, optional data-only Omarchy, scoped agent proof.
No production composition, hardware write adapter, Three.js, model transport
or user-selected product identity is assumed.

This document describes the scaffold only; consumers replace it with their
own product truth rather than inheriting illustrative fixture behavior.

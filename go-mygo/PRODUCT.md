# Native template purpose

Audience: byteowlz developers scaffolding a lightweight native desktop tool.
Task: expose one deterministic Go service through native MyGo GPU controls
and a semantic JSON CLI with portable config/design/evidence contracts.

The user confirmed fully native UI: no HTML/webview/Bun frontend/typed IPC.
No production composition, hardware write backend, 3D engine, model transport
or product-specific identity is assumed. Consumers replace fixture behavior
and establish their own Studio-approved surface and safety proof.
